# Local Mama voice agent — deployed to LiveKit.
#
# At the repo root, not under agent/, because `lk agent deploy` detects a
# Python project by a root manifest and does not follow `-r` includes. The
# root Dockerfile builds the agent too, so root == the LiveKit deployable.
# The backend keeps its own pins in backend/requirements.txt.
#
# Four things. No database driver, no Sarvam, no WhatsApp, no embedding model:
# this process talks, and everything it learns leaves over HTTP.
#
# Pinned exactly. Three modules carry "verified against livekit-agents 1.6.7"
# comments, and a floating range is how a build three weeks from now picks up a
# version that changes turn-taking with no test gate in between.

livekit-agents==1.6.7
livekit-plugins-openai==1.6.7
pydantic==2.10.4
python-dotenv==1.0.1
